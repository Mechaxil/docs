  ## Quick start (MicroPython)

  1. Install [Thonny](https://thonny.org/) and connect your Pico over USB.
  2. Seat the Pico on the I/O board, then wire your peripheral to labeled **GP** pins.
  3. Flash MicroPython firmware from Thonny if prompted.

  ```python
  from machine import Pin
  import time

  led = Pin(16, Pin.OUT)  # example: GP16

  while True:
      led.toggle()
      time.sleep(0.5)
  ```

  Change `16` to match the silkscreen label you used.
