  ## Quick start (<GlossaryTerm term="MicroPython" />)

  1. Install <GlossaryTerm term="Thonny" /> and connect your Pico over USB.
  2. Seat the Pico on the I/O board, then wire your peripheral to labeled **GP** pins.
  3. Flash <GlossaryTerm term="MicroPython" /> firmware from <GlossaryTerm term="Thonny" /> if prompted.

  ```python
  from machine import Pin
  import time

  <GlossaryTerm term="LED" /> = Pin(16, Pin.OUT)  # example: GP16

  while True:
      <GlossaryTerm term="LED" />.toggle()
      time.sleep(0.5)
  ```

  Change `16` to match the silkscreen <GlossaryTerm term="label" /> you used.
