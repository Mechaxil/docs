## Dual-audience pattern

Use the **navbar toggle** (🛠️ Maker / 📐 Engineer). Choice is stored in `localStorage` and synced site-wide via React context.

| Component | Use when |
|-----------|----------|
| `<AudienceSection audience="maker">` | Show a block only in Maker mode |
| `<AudienceSection audience="engineer">` | Show a block only in Engineer mode |
| `<AudienceGate audience="engineer">` | Entire page is engineer-only (shows switch prompt otherwise) |

### Engineer-only sidebar pages

Add to frontmatter so the sidebar link hides in Maker mode:

```yaml
sidebar_custom_props:
  audiences:
    - engineer
```
