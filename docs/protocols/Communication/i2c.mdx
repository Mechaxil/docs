## Mechaxil I2C Pros and Cons

Mechaxil I2C protocol is a simple and more robust alternative to other I2C implementations, designed for ease of use in maker projects. It offers the following advantages and disadvantages:

| Advantage | Disadvantage |
|-----------|----------|
|Follows the NXP UM10204 Standard for wiring pinout|Breaks consistency with other I2C implementations but doesn't eliminate them|
|Bigger more robust connector type|Bigger footprint|
|Dual connector design both JST XH type or pinheader|Less common|
|Easier to crimp your own cables||
|Same color coding as QWIIC||
|Same wire size so it's easy to make hybrid cables||
|Cheaper to manufacture||

## I2C Pinout

Following the advice of the NXP UM10204 standard, Mechaxil I2C uses a 4-pin connector with the following pinout:
| Pin | Function | Color | Notes |
|-----|----------|-------|-------|
| 1 | SDA | Blue | Logic Level Voltage |
| 2 | VCC | Red | 3.3 V |
| 3 | GND | Black | Ground |
| 4 | SCL | Yellow | Logic Level Voltage |
