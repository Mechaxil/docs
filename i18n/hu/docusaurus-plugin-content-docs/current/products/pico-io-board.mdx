## Első lépések

Egyszerűen csatlakoztasd a Raspberry Pi Pico (1 vagy 2) kártyádat a Pico I/O Board-ba, és máris könnyen hozzáférhetsz az összes GPIO tűhöz a kivezetéseken keresztül. Használhatod prototípusgyártáshoz, teszteléshez vagy akár projektjeid állandó részeként is.
